Как работает система наград
% от кликов ⭐

Награда = X% от общего числа кликов игрока. Новичок с 1000 кликами при 20% получит 200 монет. Ветеран с 1M кликами — 200K. Все игроки получают ощутимый буст!

Монеты ★

Фиксированная сумма для всех. Хорошо для старта — все получают одинаково. Слабо мотивирует ветеранов.

Кристаллы ◆

Фиксированное число кристаллов. Сильная мотивация — кристаллы нужны для гачи. Используй для главного канала.

Рекомендация: Используй % от кликов для большинства заданий с параметром 15–25% и минимальной наградой 300–500. Так и новичок, и ветеран получат ощутимый буст. Для главного канала дай 25–50 кристаллов.

Важно: бот должен быть администратором канала

Чтобы проверка подписки работала, твой Telegram бот должен быть добавлен в канал как администратор.

Как добавить:
1. Открой канал → Управление каналом → Администраторы
2. Добавить администратора → найди своего бота
3. Дай права "Добавлять подписчиков" (минимальные права)

Полная инструкция

Пошаговый запуск за 30 минут

Шаг 1 — GitHub Pages (бесплатный хостинг)
  1. Зарегистрируйся на github.com
  2. Нажми + → New repository
  3. Назови: waifuclicker, поставь Public → Create
  4. Нажми uploading an existing file и перетащи ВСЕ файлы проекта
  5. Settings → Pages → Source: main → / (root) → Save
  6. Через ~2 минуты игра будет на https://ИМЯ.github.io/waifuclicker/
Шаг 2 — Создай Telegram бота
  1. Открой Telegram → найди @BotFather
  2. Напиши /newbot
  3. Введи название: WaifuClicker
  4. Введи username: waifu_clicker_bot (придумай своё)
  5. Сохрани полученный TOKEN
  6. В js/game.js замени строку waifu_clicker_bot на свой username
Шаг 3 — Подключи Mini App к боту
  1. В BotFather напиши /mybots → выбери бота
  2. Bot Settings → Menu Button → Edit Menu Button
  3. Введи URL: https://ИМЯ.github.io/waifuclicker/
  4. Текст кнопки: Играть ▶
  5. Теперь в боте появится кнопка открывающая игру!
Шаг 4 — Бэкенд на Render.com (для Stars и лидеров)
  1. Зарегистрируйся на render.com
  2. Создай новый Web Service → подключи GitHub репозиторий
  3. Build Command: npm install
  4. Start Command: node server.js
  5. Добавь переменную окружения: BOT_TOKEN = твой токен
  6. После деплоя скопируй URL сервера
  7. Замени в js/game.js строку API_URL на свой URL
  8. Установи webhook: открой https://твой-сервер.onrender.com/api/set-webhook?host=https://твой-сервер.onrender.com
Шаг 5 — Добавь бота в свои каналы
  1. Открой каждый канал из заданий
  2. Управление → Администраторы → Добавить
  3. Найди своего бота и добавь его
  4. Минимальные права — только "Добавлять участников"
Шаг 6 — Замена картинок персонажей
  1. Подготовь картинку (PNG/WebP, 300×400px, пропорции 3:4)
  2. Загрузи в images/anime/ или images/game/
  3. Открой js/characters.js
  4. Найди персонажа по id или name
  5. Измени строку image: "..."
  6. Загрузи на GitHub
